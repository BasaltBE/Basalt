<h1 align="center">Basalt</h1>

<p align="center">
  A high-performance and highly customizable Minecraft Bedrock Edition server software written in C# for .NET 10.
</p>

<h2 align="center">Features</h2>

<table align="center">
<tr>
<td width="50%" valign="top">

* Custom items, blocks, and entities
* Custom terrain generators and providers
* Multiple worlds and dimensions
* Crafting and custom recipes
* Custom commands and overloads
* Plugin support

</td>
<td width="50%" valign="top">

* Chests, hoppers, furnaces, and other block actors
* Farming support
* Enchantments
* Events and signals
* Scoreboards, forms, and DDUI
* Multithreading and Tracy integration
* Custom RCON

</td>
</tr>
</table>
